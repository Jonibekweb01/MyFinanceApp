# 💰 MyFinanceApp

A personal finance tracking application built with React.js 
to monitor income, expenses, and financial health in real time.

## 🚀 Features
- Track daily income and expenses
- Visual overview of spending categories
- Real-time balance calculation
- Clean and responsive UI

## 🛠️ Tech Stack
- React.js
- JavaScript (ES6+)
- CSS / Tailwind CSS
- Local Storage
